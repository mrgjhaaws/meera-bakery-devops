# 00 · Start Here — How to use this course

## Who is this for?
Students and beginners who want to go from **zero cloud knowledge** to **deploying a real
application on AWS with automation, security and monitoring**.

## The story
**Meera's Bakery Online** starts as a small idea. In every lesson Meera asks her teacher a
question a real business owner would ask. The answer is the lesson.

```
Why cloud? → What is AWS? → Which model? → Which services? → Which region? → Console
   (1)          (2)            (3)             (4)              (5)           (6)
→ IAM users → Access keys → Never leak keys → .env → Parameter Store
   (7)          (8)            (9)             (10)       (11)
→ CI/CD → Terraform → Full pipeline → Monitoring → Auto Scaling (next)
  (12)      (13)         (14)            (15)           (16)
```

## How each lesson file is organised

1. 🎯 **Learning objectives** — what you can do afterwards
2. 📖 **The story** — Meera's question
3. 🧠 **Concepts** — every panel of the infographic explained
4. 🛠️ **Hands-on, step by step** — numbered, copy-paste friendly
5. 📁 **Files in this project** — which code belongs to this lesson
6. ⚠️ **Common mistakes** — and how to fix them
7. ✅ **Best practices**
8. 📝 **Quiz** — answers hidden under *Show answers*
9. 🏠 **Assignment** — small task to prove you learned it
10. 🔑 **Key takeaway** + **हिंदी में सार**

## Learning rules
- Type the commands yourself; don't only read.
- After every hands-on, **clean up** what you created.
- If something fails, read the error, then check [troubleshooting.md](troubleshooting.md).
- Keep a notebook: one line per lesson — *"what I built, what broke, what I learned"*.
